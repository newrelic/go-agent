# v3/integrations/nrotelhybrid [![GoDoc](https://godoc.org/github.com/newrelic/go-agent/v3/integrations/nrotelhybrid?status.svg)](https://godoc.org/github.com/newrelic/go-agent/v3/integrations/nrotelhybrid)

Please note that this is **experimental** and not yet released for public use. This is subject to change in any way, to any extent, at any time.

Package `nrotelhybrid` provides a hybrid OpenTelemetry+New Relic APM mode of operation for the New Relic Go Agent.

```go
import "github.com/newrelic/go-agent/v3/integrations/nrotelhybrid"
```

For more information, see
[godocs](https://godoc.org/github.com/newrelic/go-agent/v3/integrations/nrotelhybrid).
